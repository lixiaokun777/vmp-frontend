# 前端开发指南

0.7.0 新增外部 `mobile-navigation.js`，须在 `app.js` 前加载并纳入发布语法检查。小于等于 580px 时使用既有导航作为抽屉，沿用角色裁剪；遮罩/Escape/导航/退出/恢复桌面尺寸均关闭，归还焦点并恢复 body 的原滚动样式。不要把移动交互写入内联脚本，以保持现有 CSP。

**内容变更必须同步 bump `?v=`**：修改任何第一方 JS/CSS 时更新 `index.html` 对应资源版本，新增脚本也必须显式引入。版本查询参数与 no-store 响应共同避免混用旧脚本。修改时不得遗漏脚本原有的加载顺序。

`field()` 的 `inlineError:true` 生成带唯一 id 的错误槽；`setFieldError()` 使用 textContent 更新中文文案并维护 aria-invalid/aria-describedby，保留原 hint 关联。`bindInlineValidation()` 在 blur/提交时校验，出现错误后输入即重新校验。仅申请表单和本人改密弹窗开启 novalidate，由统一校验接管。实例名严格匹配当前后端 `^[a-zA-Z0-9-]{1,48}$`（需求中的 64 位示例不是当前后端规则）；用途去空白后非空，无新增最小长度。通用管理弹窗继续使用既有原生校验。

实例任务历史的 `taskTypeLabels` 采用中文主文案与英文代码副标题；错误码和 `failureDiagnosis()` 保持原语义。LDAP 安全警告只在 ldap:// 且未启用 StartTLS 时显示，不阻断配置保存。通知设置支持 `notify_platform_health`，省略时由后端保留原值，默认开启且仍受通知总开关限制。

`notifications.js` 提供管理员通知配置及发送记录页，先于 `app.js` 加载。凭据输入框为密码类型，不填已有明文，只展示打码地址。记录刷新只更新历史表格，避免丢失未保存的配置；群测试明确告知将向已保存地址发送真实消息。

`platform.js` 在 `app.js` 前加载，仅定义第一方函数与常量，运行时使用统一鉴权 API：平台策略、实例自动续期、代理/转交、镜像宿主同步矩阵和不可逆历史清理流程。不得将测试 fixture 逻辑放进 `web/` 或生产镜像。

## 页面范围

`web/index.html` 提供完整导航：普通用户的“我的概览”、申请虚拟机、我的虚拟机、我的申请，以及管理员的资源总览、待我审批、全部实例、宿主机、镜像、资源规格、网络 IP、用户管理、LDAP 配置和操作审计。普通用户登录后先进入个人概览，不再直接落到申请表单。

个人概览只读取 `/me/overview` 和当前账号实例，展示在用台数、配额占用及最近到期。实例详情监控读取 `/instances/{id}/metrics`，无采样时展示等待态，不能将缺失值画成 0。“我的申请”同时读取审批记录和本人 `/applications`，结构化错误码必须映射为中文下一步建议，后台错误文本继续按不可信内容编码。

未登录时只显示双栏登录页，平台账号与已同步 LDAP 账号使用可点击的独立选项卡。管理员显示完整导航、待我审批、用户管理和独立 LDAP 配置页；普通用户只显示申请虚拟机、我的虚拟机和我的申请。初始本地密码必须在首次登录时修改。

静态资源修改后必须同步更新 `index.html` 中的版本查询参数。Nginx 对页面、样式和脚本返回 `no-cache, no-store`，防止浏览器混用不同发布版本。

用户界面统一使用正式平台名称，不展示开发版、开发环境、V1 或 Provider 等内部环境标识。环境差异只保留在部署配置和运维文档中。

登录页右侧表单使用统一的最大宽度和水平中轴。账号切换、说明、输入框、错误提示、提交按钮和帮助文字不得因各自的外边距规则产生左右错位。

我的虚拟机只局部刷新实例表格，不允许定时器重绘整个页面或导航。用户切换会话时必须先清空 `#content`、详情实例 ID 和导航高亮，首登强制改密弹窗背后不得保留上一位用户的数据。

每次导航递增 `renderSequence`，登录/退出递增 `sessionEpoch`。API 读取响应与 JSON 后均核对上下文；页面最终插入前再次核对代际。导航和会话切换会取消请求与 `schedulePageWork` 登记的延时任务，取消结果不显示为操作失败。请求取消不等于撤销后端已经执行的写操作，重新进入页面时以服务器状态为准。异步页面禁止绕过这条链路写入 DOM；通知记录局部刷新同样使用统一 `api()`。

一次性凭据页必须提供密码、SSH 命令和完整连接信息的独立复制入口，并在用户勾选确认保存前禁用离开按钮。用户和实例管理列表需要保留搜索、筛选、分页和 CSV 导出能力。

`我的虚拟机` 和 `全部实例` 页面提供开机、关机、重启、续期、恢复、普通释放和立即删除操作。普通释放会让实例关机并保留 7 天，期间磁盘与原 IP 均不释放，用户可自助恢复；保留期结束才删除数据、释放 IP 和宿主机配额。立即删除跳过保留期，但仍需等待 Agent 确认虚拟机和磁盘删除成功后再释放资源。创建、续期和恢复在 7 天以内自动执行，超过 7 天进入管理员审批，审批前不占用资源。

续期和恢复表单必须填写原因。审批默认 24 小时有效，用户可撤回待审批记录，拒绝、超时、执行失败或主动撤回后可改成不超过 7 天的短租期立即重提；管理员可调整租期批准或批量审批，调整值必须覆盖创建、续期或恢复的实际执行租期。每台实例最多恢复一次，恢复后再次释放会直接删除。

管理页支持新增、维护和删除网络、资源规格、本地/远程镜像及宿主机纳管记录，并支持修改宿主机调度配额。网络表单直接维护唯一 IP 起止范围，保存后替换旧的空闲地址池，不再提供独立的追加范围入口。宿主机物理事实和安全上限只由 Agent 上报，Web 配额不能超过该上限。

删除操作遵守引用保护：存在非空闲 IP 的网络或 IP 范围不可删除；被申请单引用的规格和镜像只能停用；宿主机必须已离线且没有活动实例或执行中任务。删除镜像只移除平台元数据，不删除本地镜像文件或远程对象；删除宿主机纳管记录不会操作宿主机上的外部虚拟机。

当前页面通过 `#/页面名` 写入浏览器地址；实例详情还会包含实例 ID。刷新时恢复原位置，已完成删除的实例不展示。服务器分页均通过 `listURL()` 发真实筛选参数，不先取全量切片。`refreshPageData()` 只更新已编码的结果区及状态操作栏，搜索输入/光标、导航和配置表单保留；返回后校验会话/导航/局部请求三个代际。中文输入组合期间不触发半成品搜索。

持续刷新范围包括本人/全部实例、实例详情、我的申请/待审批、镜像矩阵和网络 IP。后台页、弹窗/警告、执行中操作、正在鼠标交互或选中的批量审批暂停轮询；按钮保持焦点不再永久阻止刷新。网络卡片计数和地址结果局部更新，搜索字段不销毁，探测按钮消失后焦点保留在同一地址行。审批旧记录可分页检索，不仅展示最近 30 条。聚合使用服务器 `total/expiring_total/usage`，CSV 逐页导出最多 10000 条并防公式注入，不能把当前页冒充全集。

网络复核使用 `requestIPProbe()` / `requestNetworkProbe()`，同一对象在途不能重复提交。只允许管理员操作无实例关联的 QUARANTINED 地址，单独“重新探测”传 false，“探测并解除隔离”和批量确认传 true。解除始终由服务器探测结果决定，没有手工强制清空状态的接口。批量 limit 默认 32、范围 1–64，必须显示排队、跳过、remaining（UNKNOWN / ERROR 尚未复核或异常待查量）及 confirmed_in_use（已确认占用仍隔离量），不能把所有隔离地址称作待查或把排队称作释放成功；未知状态不拼接 CSS。last_probe_message 和 last_probe_host 等不可信字段均按上下文编码。

实例 retry 返回 recovery_pending 时只能提示“正在复核隔离 IP”，不提示创建完成；显示任务 / 详情真实消息，复核成功后服务器自动继续原创建。页面必须解释平台保留 IP 不能代替外部 DHCP 地址池排除，恢复和开机也要重新检测冲突。

管理表单必须使用 `modal-root` 内的统一弹窗，禁止使用 `prompt` 或连续多次弹窗收集一个资源的字段。宿主机额度表单同时展示 CPU、内存、磁盘的已用量、当前额度和 Agent 上限；镜像表单根据来源类型切换本地路径或远程 URL、SHA-256 和缓存文件字段。

短时成功、提醒和一般错误使用页面顶部居中的分级通知，最多同时显示三条并允许手动关闭。虚拟机申请失败等阻断主流程的错误使用居中高可见弹窗；后端错误必须先转换为中文，并在资源不足、IP 耗尽等场景给出用户可执行的下一步建议。

## 代码约定

警告弹窗统一保留 `.alert-symbol`、`.alert-copy` 与 `.alert-actions`。正文固定在第二列首行，按钮位于独立底部行并留出间距；不要因省略图标让 CSS 自动把正文排入图标窄列。一次性虚机密码与宿主令牌离开确认共用此布局，窄屏下允许按钮折行，不改变未保存凭据的确认与焦点保护。

2026-10-23 本轮验收：`node --test tests/*.test.js` 67 项通过；本机隔离浏览器验证 2560、1440、768、390、320px 下两种凭据文案、正文与按钮不重叠，验证 Tab/Shift+Tab 环绕、继续保存不丢失状态及确认离开。桌面/移动截图保存在本地 `output/playwright/credential-alert-{desktop,mobile}.png`（不随镜像或 Git 发布）。隔离测试未连接生产 API、签发真实令牌或操作宿主虚拟机。

- `app.js` 负责 API 请求、状态和页面交互。
- `styles.css` 保留基础样式，`v1.css` 放置当前版本布局。
- 所有用户可见文案使用中文；协议状态码保留英文原值。
- 不在浏览器中保存令牌、虚机密码或其他敏感信息。
- 登录身份来自 HttpOnly Cookie，禁止使用客户端用户名参数模拟身份。
- 初始密码只保留在当前页面的内存状态中，不写入 `localStorage`、`sessionStorage` 或 URL。
- API/Agent/地址栏数据都不可信。文本和带引号的属性使用 `esc()`，路径片段使用 `pathID()`；数值须编码或经 `numeric()` 转换，不允许直接拼接未知状态、ID、版本、错误文本或网络名称。
- 页面模板中的 `action` / `content` 只能由第一方静态模板与已经编码的数据生成，不接受后台返回的任意 HTML。
- 使用 `resource_snapshot` 展示实际分配量，按 `flavor_id` 聚合占用，不能以可修改名称或当前套餐资源值替代实例快照。
- 控制台地址栏只传实例 ID、模式和显示名称；连接 URL 从同源 `console-sessions` 接口取得并校验协议/路径。票据不写入浏览器地址、存储或日志。
- 所有 Cookie 登录的非 GET/HEAD 请求必须携带 `X-VMP-Request: 1`。业务页面使用统一 `api()`；控制台的独立 `fetch()` 同样遵循该协议。增加新的网络入口时必须补齐该头并加入隔离回归断言。
- 异步按钮由 `runButton()` 统一禁止重复并接管错误；表单提交必须检查 disabled。归档二进制下载虽为 GET，仍需校验会话/导航代际、响应与 SHA-256，禁止向切换后的账号下载旧响应。
- `showFormModal()` 使用 dialog/aria-modal、字段 for/id、背景 inert、Tab/Shift+Tab 环绕、Escape 与焦点恢复。首次强制改密不允许用 Escape 绕过；凭据窗口和页面离开需确认保存，不在确认前销毁密码。

## 隔离自动化回归

无需安装依赖，使用支持 `node:test` 的 Node.js 执行：

```bash
node --check web/app.js
node --check web/notifications.js
node --check web/platform.js
node --check web/console.js
node --test tests/frontend.test.js
```

用例直接载入第一方脚本，模拟 DOM、响应、延迟 Promise 与定时器。验证跨账号旧页面、导航竞态、已取消请求和延迟 JSON、过滤器清理、HTML/属性编码、LDAP 首配与来源一致性、同名规格/快照及旧 hash 控制台地址拒用。不会连接真实数据库、LDAP、Webhook 或 KVM。

实际浏览器回归可单独运行 `node tests/browser-fixture.js`，仅监听 `127.0.0.1:18882`，使用明示的隔离数据与严格 CSP。通过 Playwright CLI 验证搜索保焦点、分页请求、弹窗键盘闭环、策略/代理/镜像同步请求、归档下载确认和凭据离开提醒。该测试服务不读生产环境变量或外部数据；完成后停止进程。生产页面始终调用真实后端，不使用 fixture。

## 验证

1. 使用 Nginx 启动静态页面。
2. 按管理员/普通用户分别验证实际导航、页面权限与全部新增入口。
3. 在开发者工具中确认 API 请求均使用 `/api/v1` 相对路径。
4. 验证空数据、API 错误和正常数据三种状态。
5. 提交申请后验证一次性凭据页面、复制按钮和非 HTTPS 环境的复制回退逻辑。
6. 验证普通释放进入保留期后原 IP 仍为已分配，立即删除或保留期清理成功后 IP 才恢复为空闲。
7. 验证被引用或占用的管理资源会拒绝删除，未使用的临时资源能够正常删除。
