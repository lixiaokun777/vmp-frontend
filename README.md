# VMP Frontend

VMP 虚拟机申领平台的前端项目。第一版覆盖资源总览、申请虚拟机、我的虚拟机，以及全部实例、宿主机、镜像、资源规格和网络 IP 等平台管理页面。

登录页使用独立的双栏工作台界面，明确区分可点击的平台账号和 LDAP 账号入口。管理员可访问平台管理、用户管理、待我审批和独立的 LDAP 配置页；普通用户只显示申请虚拟机、我的虚拟机和我的申请，并由后端强制进行数据隔离。

实例列表已支持开机、关机、重启、续期、带 7 天保留期的普通释放和不保留数据的立即删除。普通释放期间会同时保留虚拟机磁盘和原 IP；保留期结束或立即删除成功后，才释放 IP 与宿主机配额。

保留期实例提供用户自助“恢复”入口，恢复原磁盘和原 IP。创建、续期或恢复不超过 7 天自动执行；超过 7 天进入管理员审批，批准前不占用宿主机和 IP 资源。

管理员首页和导航展示待审批数量，登录时主动提醒。审批默认 24 小时有效，支持用户撤回、撤回后改短租期重提、管理员调整租期批准和批量处理；调整后的租期直接用于实例执行，交付失败会回写为“已通过但执行失败”。每台实例最多恢复一次，恢复后再次释放不再进入第二次保留期。

运行中实例的详情页支持重新生成一次性登录密码。新密码只在当前弹窗展示，底层通过 QEMU Guest Agent 异步应用，前端不会持久化明文。

实例详情页同时提供 VNC 与串口控制台，用于网络或 SSH 故障排查；控制台在独立窗口打开，使用 5 分钟有效且只能核销一次的票据。旧票据被拒绝时会明确提示点击右上角“重新连接”。管理端“操作审计”页支持人工/系统事件隔离、搜索、动态动作、资源类型、结果、时间范围筛选、分页与 JSON 详情展开。

申请成功页分别提供密码、SSH 命令和完整连接信息复制，并要求确认凭据已保存后才能离开。实例列表显示相对到期时间，并对 24 小时内到期的资源分级高亮和发送站内提示；管理员可搜索、筛选、分页和导出用户及实例列表。

管理员可在 Web 中定义和安全删除网络与 IP 范围、自定义资源规格、登记本地/远程镜像，并在 Agent 安全上限内调整宿主机调度配额。管理资源只有在未被引用或占用时才允许删除。

网络和唯一有效的 IP 起止范围在同一个表单中维护，地址状态使用中文展示。页面地址写入 URL 片段，浏览器刷新后会回到刷新前的功能页。

所有管理操作使用平台内表单，一次展示完整字段、当前值、资源上限和校验错误，不使用浏览器原生连续输入框。

界面采用极简浅色视觉体系：白色侧边栏、双层吸顶导航、中性灰内容背景、黑色主操作按钮和低阴影卡片。登录、资源卡片、表格、表单、弹窗、状态标签及移动端布局使用同一套设计变量；本次视觉升级不改变现有接口、权限、操作入口和业务流程。

申请页使用固定规格卡片并实时汇总镜像、网络、租期、预计到期和资源占用；资源规格页展示各规格运行、保留及内存预占情况。网络页同时展示完整地址池和已占用 IP 明细，用户管理将搜索、来源、角色筛选和分页集中在表格中。LDAP 配置采用分段表单和独立状态侧栏，展示真实配置状态与同步用户数量。

## 技术形态

- 原生 HTML/CSS/JavaScript，无构建依赖。
- Nginx 托管静态文件并将 `/api/` 反向代理到后端。
- 静态页面、样式和脚本禁止长期缓存，发布后不会混用新旧版本。
- 数据来自 `/api/v1`，后端不可用时会显示明确错误。
- 申请成功后展示 IP、用户名和仅显示一次的初始密码，支持一键复制。

## 目录

```text
web/                 页面、交互和样式
deployments/         Nginx 部署配置
docs/                开发和接口依赖文档
Dockerfile           静态站点镜像
CHANGELOG.md         版本变更记录
```

## 本地预览

```bash
docker build -t vmp-frontend:dev .
docker run --rm -p 8080:80 vmp-frontend:dev
```

开发环境如果后端不在 Docker 网络中，需要将 `deployments/nginx.conf` 的 `proxy_pass` 改为实际控制面地址。

## 文档同步规则

功能、页面入口、API 依赖或部署方式变更时，同一次提交必须更新 `README.md`、`docs/` 中对应文档和 `CHANGELOG.md`。项目内人工编写的注释统一使用中文。
