# VMP Frontend

VMP 虚拟机申领平台的前端项目。第一版覆盖资源总览、申请虚拟机、我的虚拟机，以及全部实例、宿主机、镜像、资源规格和网络 IP 等平台管理页面。

实例列表已支持开机、关机、重启、续期、带 7 天保留期的普通释放和不保留数据的立即删除。普通释放期间会同时保留虚拟机磁盘和原 IP；保留期结束或立即删除成功后，才释放 IP 与宿主机配额。

管理员可在 Web 中定义和安全删除网络与 IP 范围、自定义资源规格、登记本地/远程镜像，并在 Agent 安全上限内调整宿主机调度配额。管理资源只有在未被引用或占用时才允许删除。

网络和唯一有效的 IP 起止范围在同一个表单中维护，地址状态使用中文展示。页面地址写入 URL 片段，浏览器刷新后会回到刷新前的功能页。

所有管理操作使用平台内表单，一次展示完整字段、当前值、资源上限和校验错误，不使用浏览器原生连续输入框。

## 技术形态

- 原生 HTML/CSS/JavaScript，无构建依赖。
- Nginx 托管静态文件并将 `/api/` 反向代理到后端。
- 数据来自 `/api/v1`，后端不可用时会显示明确错误。
- 申请成功后展示 IP、用户名和仅显示一次的初始密码，支持一键复制。

## 目录

```text
web/                 页面、交互和样式
deployments/         Nginx 部署配置
docs/                开发和接口依赖文档
Dockerfile           静态站点镜像
CHANGELOG.md         版本变更记录
```

## 本地预览

```bash
docker build -t vmp-frontend:dev .
docker run --rm -p 8080:80 vmp-frontend:dev
```

开发环境如果后端不在 Docker 网络中，需要将 `deployments/nginx.conf` 的 `proxy_pass` 改为实际控制面地址。

## 文档同步规则

功能、页面入口、API 依赖或部署方式变更时，同一次提交必须更新 `README.md`、`docs/` 中对应文档和 `CHANGELOG.md`。项目内人工编写的注释统一使用中文。
