当前发布版本：`0.7.0`，镜像由版本标签工作流发布。

本轮推荐配套版本：前端、后端、Agent 均为 `0.7.0`。增加移动抽屉导航、申请/改密内联校验、任务中文文案、登出恢复、LDAP 明文连接提示和平台健康告警开关。升级步骤见 [0.7.0 发布与升级指南](https://github.com/lixiaokun777/vmp-backend/blob/codex/reliability-0.7.0/docs/0.7.0发布与升级.md)。发布不自动更新现有服务器。

隔离 IP 复核增强：管理员在“网络 IP”可对未关联实例的隔离地址“重新探测”或“探测并解除隔离”，也可按网络批量复核（默认每轮 32 条，最多 64 条）。这是异步探测，不是强制释放；只有确认未占用且仍无实例关联时才恢复空闲。页面持续局部更新状态、探测宿主、时间和说明，保留搜索焦点及未提交弹窗。此能力需要配套本次后端和 Agent 探测协议，既有固定版本不能仅刷新获得。

平台保留 IP 不能阻止外部 DHCP 再次分配同一地址，管理员必须从 DHCP 动态池排除平台地址范围。恢复或开机前仍会重新检查冲突。失败实例没有空闲地址时，“重试创建”可能先进入 IP 复核，而不是立即创建；页面显示真实复核结果，成功后由后端自动继续原创建，不需要反复点击重试。

0.5.1 回归修复：导航和登录会话使用独立代际及请求取消，旧请求、旧搜索定时器不能回写新页面或另一账号；动态字段按上下文编码。用户、实例、审批与 IP 采用服务端分页和完整筛选，搜索仅局部刷新结果，不销毁输入焦点。详情、审批、实例和镜像状态持续局部刷新；统一操作错误提示与重复点击保护。

新增管理员“平台策略”：公平使用配额、最长连续/未来租期、有限自动续期与历史保留。实例详情可配置有限次数自动续期；审批支持按有效期设置代理与转交；远程镜像明确选择宿主同步并逐宿主展示校验结果。历史数据按“生成归档→下载校验和备份→确认清理源记录→确认删除归档”闭环管理，清理不会自动发生。

通用弹窗提供 dialog 语义、关联标签、Tab 焦点约束、Escape 关闭和焦点恢复；未确认保存凭据时，导航、关闭、退出与刷新会先提醒。LDAP 首配刷新、LDAP 登录来源同步、按规格 ID/分配快照汇总及全量到期统计已校正。当前推荐后端和 Agent 均为 `0.6.0`，不能只升级前端而忽略配套组件。

静态入口提供禁止内联脚本与动态执行的 CSP。控制台通过平台同源 WebSocket 桥接，不向浏览器开放宿主机端口；地址栏不保存票据。Nginx 需要同步升级连接头配置。`node --test tests/*.test.js` 与仅监听本机的 `tests/browser-fixture.js` 提供隔离回归，不连接生产数据库、LDAP、Webhook 或 KVM。

管理员“通知设置”页可配置 WPS / WOA 群机器人、提醒时间、签名密钥与平台链接，发送测试消息并分页查看记录。默认关闭，保存配置并测试后可启用。当前推荐配套后端 `0.6.0`。

通知增加审批、交付失败及宿主离线/恢复选项；总开关未启用时不会发送这些事件。页面不会自行向群聊发送测试。

VMP 虚拟机申领平台的前端项目。第一版覆盖资源总览、申请虚拟机、我的虚拟机，以及全部实例、宿主机、镜像、资源规格和网络 IP 等平台管理页面。

0.6.0 为普通用户增加“我的概览”，集中展示个人在用资源、平台用户配额和到期风险；实例详情展示近 24 小时 CPU/内存基础曲线。“我的申请”同时展示自动交付记录，并把 Agent 结构化错误码翻译为可执行的中文排障建议。该能力需配套后端和 Agent `0.6.0`。

全局操作反馈使用顶部居中的中文分级通知；资源不足等关键申请错误使用居中弹窗，并同时说明失败原因和下一步处理建议。

登录页使用独立的双栏工作台界面，明确区分可点击的平台账号和 LDAP 账号入口。管理员可访问平台管理、用户管理、待我审批和独立的 LDAP 配置页；普通用户只显示申请虚拟机、我的虚拟机和我的申请，并由后端强制进行数据隔离。

实例列表已支持开机、关机、重启、续期、带 7 天保留期的普通释放和不保留数据的立即删除。普通释放期间会同时保留虚拟机磁盘和原 IP；保留期结束或立即删除成功后，才释放 IP 与宿主机配额。

保留期实例提供用户自助“恢复”入口，恢复原磁盘和原 IP。创建、续期或恢复不超过 7 天自动执行；超过 7 天进入管理员审批，批准前不占用宿主机和 IP 资源。

管理员首页和导航展示待审批数量，登录时主动提醒。审批默认 24 小时有效，支持用户撤回、撤回后改短租期重提、管理员调整租期批准和批量处理；调整后的租期直接用于实例执行，交付失败会回写为“已通过但执行失败”。每台实例最多恢复一次，恢复后再次释放不再进入第二次保留期。

运行中实例的详情页支持重新生成一次性登录密码。新密码只在当前弹窗展示，底层通过 QEMU Guest Agent 异步应用，前端不会持久化明文。

实例详情页同时提供 VNC 与串口控制台，用于网络或 SSH 故障排查；控制台在独立窗口打开，使用 5 分钟有效且只能核销一次的票据。旧票据被拒绝时会明确提示点击右上角“重新连接”。管理端“操作审计”页支持人工/系统事件隔离、搜索、动态动作、资源类型、结果、时间范围筛选、分页与 JSON 详情展开。

申请成功页分别提供密码、SSH 命令和完整连接信息复制，并要求确认凭据已保存后才能离开。实例列表显示相对到期时间，并对 24 小时内到期的资源分级高亮和发送站内提示；管理员可搜索、筛选、分页和导出用户及实例列表。

管理员可在 Web 中定义和安全删除网络与 IP 范围、自定义资源规格、登记本地/远程镜像，并在 Agent 安全上限内调整宿主机调度配额。管理资源只有在未被引用或占用时才允许删除。

网络和唯一有效的 IP 起止范围在同一个表单中维护，地址状态使用中文展示。页面地址写入 URL 片段，浏览器刷新后会回到刷新前的功能页。

所有管理操作使用平台内表单，一次展示完整字段、当前值、资源上限和校验错误，不使用浏览器原生连续输入框。

界面采用极简浅色视觉体系：白色侧边栏、双层吸顶导航、中性灰内容背景、黑色主操作按钮和低阴影卡片。登录、资源卡片、表格、表单、弹窗、状态标签及移动端布局使用同一套设计变量；本次视觉升级不改变现有接口、权限、操作入口和业务流程。

申请页使用固定规格卡片并实时汇总镜像、网络、租期、预计到期和资源占用；资源规格页展示各规格运行、保留及内存预占情况。网络页同时展示完整地址池和已占用 IP 明细，用户管理将搜索、来源、角色筛选和分页集中在表格中。LDAP 配置采用分段表单和独立状态侧栏，展示真实配置状态与同步用户数量。

## 技术形态

- 原生 HTML/CSS/JavaScript，无构建依赖。
- Nginx 托管静态文件并将 `/api/` 反向代理到后端。
- 静态页面、样式和脚本禁止长期缓存，发布后不会混用新旧版本。
- 数据来自 `/api/v1`，后端不可用时会显示明确错误。
- 申请成功后展示 IP、用户名和仅显示一次的初始密码，支持一键复制。

## 部署

第一次部署请从 [完整新手部署手册](https://github.com/lixiaokun777/vmp-backend/blob/main/docs/部署指南.md) 开始。推荐使用后端仓库提供的完整 Compose，直接拉取固定版本镜像并一次启动 PostgreSQL、控制面和 Web；已有 PostgreSQL 也可由后端自动初始化与迁移，无需挂载 SQL。前端单独构建、源码构建、已有网关接入、HTTPS 和升级说明见 [前端部署文档](docs/部署.md)。

建议使用独立域名的根路径，例如 `https://vmp.example.com/`。当前静态资源和 API 使用根路径，不能仅靠设置 `PUBLIC_BASE_URL` 把平台挂到 `/vmp/`；产品没有这个应用环境变量。通知设置的“平台访问地址”只决定消息里的跳转链接，不改变反向代理、Cookie 或控制台来源校验。

## 本地预览

```bash
docker build -t vmp-frontend:dev .
docker run --rm -p 8080:80 vmp-frontend:dev
```

开发环境如果后端不在 Docker 网络中，需要将 `deployments/nginx.conf` 的 `proxy_pass` 改为实际控制面地址。
